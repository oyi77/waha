⚙️ Engine Comparison & Selection

Choose the right WhatsApp engine for your use case

NOWEB
Recommended
Pure Node.js, no browser required. Low memory, best for servers and production workloads.
WEBJS
Stable
Full whatsapp-web.js with Chromium. Higher memory but maximum feature compatibility.
WPP
Stable
WPPConnect engine. Browser-based alternative with some unique features not in WEBJS.
GOWS
Beta
Experimental Go-based implementation. Fastest startup but limited feature set.

Which Engine Should I Use?

Do you need low memory usage (e.g. running on a small VPS or many sessions)?
Yes → Use NOWEB (no Chromium, ~50MB/session)
No → Continue below
Do you need maximum feature compatibility or have existing whatsapp-web.js code?
Yes → Use WEBJS (full Chromium, ~400MB/session)
No → Continue below
Do you need WPPConnect-specific features (labels, communities)?
Yes → Use WPP (Chromium, WPPConnect fork)
No → Continue below
Are you experimenting and need the fastest possible startup?
Yes → Use GOWS (experimental, limited features)
Default → Use NOWEB (safe default for most use cases)
