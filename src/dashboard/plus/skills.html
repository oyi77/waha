🧠 Claude Skills for WAHA

Ready-to-use Claude Code skill definitions for WhatsApp automation

/waha-send Send Messages
Send WhatsApp messages directly from Claude. Ask Claude to send a message and it will call the WAHA API automatically.
/waha-broadcast Broadcast
Broadcast a message to multiple WhatsApp contacts at once. Claude will ask for the contact list and message, then send to all of them.
/waha-status Session Status
Check WAHA session status and get the QR code for authentication. Claude will report the session state and show the QR code URL if needed.

How to Install

1
Copy a skill above
Click "Copy" on any skill definition to copy the markdown content to your clipboard.
2
Create the skill file
Save the copied content to ~/.claude/skills/waha-send.md (or the appropriate skill name). Create the directory if it doesn't exist: mkdir -p ~/.claude/skills
3
Set your WAHA URL
Update the WAHA_URL and API_KEY placeholders in the skill file with your actual WAHA instance URL and API key.
4
Use in Claude Code
Run /waha-send in Claude Code to invoke the skill. Claude will ask for the required details and send the message.

Alternative: WAHA MCP Connection

Instead of individual skills, connect Claude Code directly to WAHA via MCP for full tool access. This gives Claude access to all 15 WAHA tools without any skill files.

Claude Code Settings (~/.claude/settings.json)

After adding this config, restart Claude Code. You'll see all waha_* tools available automatically.
